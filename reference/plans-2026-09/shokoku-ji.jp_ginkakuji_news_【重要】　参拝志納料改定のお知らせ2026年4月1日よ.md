# 【重要】　参拝志納料改定のお知らせ(2026年4月1日より)

2026年1月18日

２０２６年４月１日より、下記のとおり参拝志納料を改定いたします。

何卒ご理解賜りますようお願い申し上げます。

## **参拝志納料の改定について　《2026年4月1日より》**

|  |  |  |
| --- | --- | --- |
|  | **改定前** | **改定後** |
| **大人（高校生以上）** | **500円** | **1,000****円** **（変更あり）** |
| **小人（小・中学生）** | **300円** | **500****円** **（変更あり）** |
| **小学生未満** | **免　除** | **免　除** **（変更なし）** |
| **障がい者等減免** | **100円** | **100円** **（変更なし）** |
