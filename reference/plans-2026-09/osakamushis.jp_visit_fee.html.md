## 観覧料・利用料

（2025.6.5更新）

#### 開館時間

**午前9時30分**から**午後5時**まで

* 入館は閉館の30分前まで

#### 休館日

**火曜日**（祝日の場合は翌日）
　　**年末年始**（12月28日から1月4日）

#### 住所・電話番号

〒540-0008　大阪市中央区大手前4丁目1-32

TEL:06-6946-5728（ゴーナニワ）／ FAX:06-6946-2662

#### 常設展示　観覧料

|  |  |  |
| --- | --- | --- |
|  | 個人 | 団体 |
| 大人 | 600円 | 540円 |
| 高校生・大学生 | 400円 | 360円 |
| 中学生以下 | 無料 | |
| 大阪市在住の65歳以上の方 |
| 障がい者手帳等をお持ちの方 （介護者1名を含む） |

* 団体は20名様以上です。なお、スムーズな手続きや見学をしていただくため、事前に団体申込書での申請をお願いいたします。詳しくは[コチラ](group.html)をご覧下さい。
* 高校生・大学生チケットの購入時は証明証をご提示ください。
* 大阪市内在住の65歳以上の方は、敬老優待乗車券、運転免許証など証明できるものをご提示ください。
* 観覧券の購入には、現金の他、以下の決済方法をご利用いただけます。  

  ・Visa / Mastercard / JCB / American Express / Diners Club / Discover  
  ・iD / QUICPay / UnionPay(銀聯)  
  ・d払い / PayPay / au Pay / Jcoin / SmartCode /   
  　Alipay / WeChatPay / Coin+ / R pay
* 障害者手帳アプリ「ミライロ ID」のご提示でも減免が適用されます（付添1名を含む）。「ミライロ ID」詳細は[こちら](https://mirairo-id.jp/)（https://mirairo-id.jp/）  
  ※ なお、スマートフォン画面にて必要な情報が確認できない場合は、原本のご提示をお願いすることがあります。

常設展示（個人）のチケットはオンラインでも販売しています。  
[![公式オンラインチケット](fee/online-ticket_001.png)](https://www.e-tix.jp/mus-his.city.osaka/)

#### 常設展示　ミュージアムガイド

常設展示場内の50カ所で、展示解説を楽しむことができます。詳細は[コチラ](onsei_guide/onsei_guide.html)をご覧下さい。

|  |  |
| --- | --- |
| ４か国語対応 （日本語・English・中文・한국어） | 1台 400円 |

#### 特別展

* 常設展とは別に観覧料が必要です。詳細については、各展覧会のページをご覧下さい。

#### なにわ歴史塾

どなたでも無料で利用できる学習情報センターです。詳しくは[コチラ](naniwajuku.html)をご覧下さい。

#### 難波宮遺跡探訪

地下に保存している古代の難波宮跡をご案内します。
  
（定員：先着20名／14時・15時出発）

詳しくは[コチラ](../news/zyousetu/b1.html)をご覧下さい。
