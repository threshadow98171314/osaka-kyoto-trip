# 清水寺の拝観料と拝観時間｜2025年最新情報とお得な楽しみ方

## 清水寺の拝観料は？

2024年4月より、清水寺の拝観料が改定され、以下の料金となっています。

|  |  |  |
| --- | --- | --- |
| 区分 | 拝観料 | 胎内めぐり |
| 大人 | 500円 | 100円 |
| 中学生・小学生 | 200円 |

拝観料は当日、現地で支払い可能で、事前予約は不要です。また、障がい者手帳を提示すると、本人と付き添い1名が無料で拝観できます。

#### 

## **清水寺の拝観時間と特別拝観のスケジュール**

清水寺の拝観時間は、通常の時間帯と季節ごとの特別スケジュールがあります。特に春・夏・秋には夜間特別拝観が実施され、ライトアップされた幻想的な清水寺を楽しめます。

| 期間 | 開門時間 | 閉門時間 |
| --- | --- | --- |
| 1月1日〜3月24日 | 6:00 | 18:00 |
| 3月25日 ～ 4月3日 （春の夜間特別拝観） | 21:30  (21:00受付終了) |
| 4月4日 〜 6月30日 | 18:00 |
| 7月1日 〜 8月13日 | 18:30 |
| 8月14日 〜 8月16日 （千日詣り 夏の夜間特別拝観） | 21:30  (21:00受付終了) |
| 8月17日 〜 8月31日 | 18:30 |
| 9月1日 〜 11月21日 | 18:00 |
| 11月22日 〜 12月7日 （秋の夜間特別拝観） | 21:30  　(21:00受付終了) |
| 12月8日 〜 12月31日 | 18:00 |

お守り授与所、納経所（ご朱印）での授与は8：00頃から。夜間特別拝観は、通常の拝観料（大人500円、中学生・小学生200円）で楽しめるので、昼と夜の両方を訪れるのもおすすめです。

#### 

## **清水寺を訪れる際のポイント**

清水寺は京都を代表する観光地であり、歴史的な価値だけでなく、四季折々の美しい景観が楽しめるスポットです。特に夜間特別拝観では、ライトアップされた本堂や清水の舞台が幻想的な雰囲気に包まれ、昼間とは違った表情を見せてくれます。

拝観の際には以下の点に注意しましょう。

* **拝観料は当日現地払いで、予約不要。** 混雑時でもスムーズに入場できます。
* **夜間特別拝観は特に混雑しやすいので、開始直後の時間帯が狙い目。**
* **紅葉シーズンや桜の時期は特に人気が高く、早めの訪問がおすすめ。**
