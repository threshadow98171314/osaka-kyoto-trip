# おこしやす。京のみやげが勢ぞろい

東海道新幹線京都駅八条口にある「アスティ京都」。老舗の京名菓をはじめ京みやげが一堂に集まっています。もちろん、おみやげ以外にも人気の雑貨店や京都を代表する名店まで揃っており、旅行者から日常で利用される方にも楽しんでいただける施設です。

![](/asty_kyoto/about_01.jpg)

# 新幹線改札内

![](/asty_kyoto/65111463d73196ae0dee2391370ec987.png)

新幹線改札内でも京都の「食」や「文化」をお楽しみいただけるよう有名店舗を多数取り揃えていますので、新幹線の発車時刻を待つちょっとしたお時間にカフェで一息ついたり、お買い物をお楽しみいただけます。  
また、佐川急便宅配カウンターを利用すれば、お手持ちのお荷物をご自宅に配送することが可能です。

# アスティスクエア

![](/asty_kyoto/IMG_3660-3_3.jpg)

京都駅南北自由通路に面し、新幹線中央口改札、近鉄京都駅改札の間に位置するアスティスクエア。観光のお客様に京都らしさを感じていただきながら、地元のお客様にも日常的にご利用いただけるエリアです。

# アスティロード

![](/asty_kyoto/about_04.jpg)

京都の人気雑貨から、老舗京土産、和食料理など買い物からお食事まですべてが揃ったエリアになります。  
八条東口改札側に位置するレストランエリア「京都おもてなし小路」では、京町家風の街並みをイメージした作りで、より京都らしさを感じながらお食事をお楽しみいただけます。
